# Vehicle Sales Dashboard

An interactive web application built with Python to explore vehicle sales advertisement data through interactive visualizations.

## Project Overview

This project was developed as part of a practical software engineering project focused on strengthening Python development workflows and complementing data-related skills.

The application uses a dataset of vehicle sales advertisements and provides interactive visualizations to explore variables such as vehicle mileage and price.

The project also covers the creation of a Python environment, dependency management, web application development and cloud deployment.

## Objectives

* Practice Python software development workflows
* Work with structured data using Pandas
* Create interactive data visualizations with Plotly
* Develop a web application using Streamlit
* Manage project dependencies and virtual environments
* Deploy a Python web application to a cloud service

## Technologies

* Python
* Pandas
* Plotly
* Streamlit
* JupyterLab
* Git
* GitHub

## Data Visualization

The project includes interactive visualizations such as:

* Histogram of vehicle mileage (`odometer`)
* Scatter plot comparing vehicle mileage and price

These visualizations provide an initial exploration of patterns within the vehicle advertisement dataset.
